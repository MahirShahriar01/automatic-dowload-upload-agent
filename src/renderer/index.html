Google Accounts

Needed to upload to Drive, read private files, and avoid public download limits.

One-time setup: connect your own Google API client

Google requires every app that uploads to Drive to use an OAuth client. It is free and takes ~3 minutes. Open the step-by-step guide.

  1. Open Google Cloud Console and create a project.
  2. Enable the Google Drive API.
  3. Configure the OAuth consent screen (External) and add your Gmail as a test user.
  4. Create OAuth client ID → Application type Desktop app → Download JSON.
  5. Click Import JSON below (or paste Client ID + Secret).

Browser Extension

Catch downloads from Chrome, Edge, Brave, Opera or Firefox and send them to DriveRelay.

Checking…

Chrome / Edge / Brave / Opera

  1. Click Show extension folder below.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode (top-right).
  4. Click Load unpacked and select the chromium folder.
  5. Pin the DriveRelay icon to the toolbar.

Firefox

  1. Click Show extension folder below.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on…
  4. Select firefox/manifest.json.
  5. For permanent install, use the signed .xpi (see README).

What the extension does

  • Automatically takes over browser downloads (files bigger than the minimum size) — falls back to the browser if the app is closed.
  • Right-click any link → Download with DriveRelay, or Download all links on a page.
  • On a Google Drive page → Relay this Drive link opens the relay form pre-filled.
  • Sends cookies + referrer so downloads that need your login keep working.
